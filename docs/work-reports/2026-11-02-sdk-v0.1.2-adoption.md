# Simpludify v0.1.2のレジストリ導入とViewport移行

## 基準

- Run To Exit main: `838f57920d82296c6b6a0a8d8f2e764bdc70e207`。
- SDKリリース元: `8122a6dc347d661da24c3df7610d4218a431c314`、タグ`v0.1.2`。
- npm公開: [Trusted Publishing 41408637470](https://github.com/oz-coden/Simpludify/actions/runs/41408637470)。CoreとWebの公開受付後、npmの反映待ちが各1分を超えたため同じアーカイブで再開している。レジストリで両方のバージョンと検証済みintegrityの一致を確認してから依存更新を行った。
- ブランチ: `feat/use-simpludify-v0.1.2`。

## 変更

- 公開npmのCore/Webを0.1.2に完全固定し、npmでlockfileを再生成。tarballやローカルパスを依存に含めない。
- CanvasPanelのFlex領域をbindViewportへ接続。Board専用ResizeObserverと固定の64/96px計算を除去。Boardの差分は18行削除・5行追加、正味13行減。
- エントリのGameをESM exportとして保持し、E2Eは本番のアセットmanifestからESMエントリを解決して公開worldToScreenを読み取る。検証専用windowグローバルは設けない。
- desktop/390/320pxのリサイズ、HUD・World入力の分離、SDK依存一覧の0.1.2を検証する。
- `src/model.ts`、整数ステップ、Conflict全体ロールバック、命令規則、表示専用Tweenを維持。

## bindViewport採用前後

従来はBoard自身がResizeObserverを生成し、画面からHUDの固定値を引いてViewportを更新していた。

```ts
const resize = () => {
  const width = game.element.clientWidth, height = game.element.clientHeight;
  if (width && height) game.setViewport({
    x: 0, y: 64, width, height: Math.max(1, height - 96),
  });
};
const observer = new ResizeObserver(resize);
observer.observe(game.element);
context.onActivate(resize);
context.onDispose(() => observer.disconnect());
```

移行後はCanvasColumnのHUD・下部ヒント間の領域を直接指定する。親Columnに`height: "100%"`を指定し、空の領域でWorldの入力を遮らない。

```ts
const region = CanvasPanel([], { grow: 1, pointerEvents: "none" });
const ui = context.canvasUI(CanvasColumn(
  [hud, region, hint],
  { padding: 10, gap: 6, height: "100%" },
));
game.bindViewport(ui, region);
```

Board全体の差分は18行削除・5行追加（13行減）。レイアウトからViewportへ座標を合わせる責務がSDKへ移り、ゲーム規則は変更していない。
