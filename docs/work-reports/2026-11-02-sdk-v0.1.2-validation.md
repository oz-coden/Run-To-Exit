## `bindViewport()`移行案

[適用候補パッチ](../migrations/sdk-v0.1.2-bind-viewport.patch)は`src/board.ts`だけを変更する。v0.1.2公開後、npm依存とlockfileを正式更新してから適用する。

- 変更前: HUDの上64px・下32pxを固定値で除外し、Board専用ResizeObserverとactivate/dispose処理を管理。
- 変更後: `CanvasPanel([], { grow: 1, pointerEvents: "none" })`をWorld用領域として確保し、UIの高さを100%にして`game.bindViewport(ui, region)`で接続。
- 差分: 18行削除・5行追加、正味13行削減。専用Observer 1個とViewport用の固定寸法3か所を除去。HUDとヒントの実際のレイアウトを基準にする。
- Tilemap.worldToTile、Tween、整数ステップモデルと命令規則は維持する。

```ts
const region = CanvasPanel([], { grow: 1, pointerEvents: "none" });
const ui = context.canvasUI(
  CanvasColumn([hud, region, hint], { padding: 10, gap: 6, height: "100%" }),
);
game.bindViewport(ui, region);
```

この例の`hud`と`hint`は既存のゲームUIを表す。完全な差分は上記パッチを参照。
